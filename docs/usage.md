# 使用說明

## 給學生

1. **照順序讀。** 第三部分的每一步都用到前一步的輸出檔，跳著做會缺檔案。
2. **每章的結構都一樣：** 學習目標 → 時間配置 → 觀念說明 → 實作（附給 AI 的提示詞範例）→ 驗證清單 → 延伸影片 → 參考文獻。
3. **提示詞是範例，不是咒語。** 請依自己的資料夾名稱、作業系統修改。AI 每次產生的程式碼都可能不同，所以每章都有「驗證清單」，用來判斷結果對不對。
4. **練習題的答案預設收合。** 先自己想，再按「查看答案」。
5. **遇到錯誤訊息時，** 先把完整錯誤訊息貼給 AI，請它解釋原因，再決定要不要照它的建議改。不要只說「不能跑」。

## 給授課教師

- 每章設計為 1 小時（約 15 分鐘講解、30 分鐘實作、15 分鐘檢討），可依班級程度合併或拆分。
- 第三部分需要在 Linux、macOS 或 Windows 的 WSL 環境執行 PLINK。若學生電腦無法安裝，可改用學校的伺服器或雲端環境。
- 第四部分以「讀懂方法、能請 AI 寫出分析流程並檢查」為目標；完整執行需要外部參考資料（例如 LD 參考面板、eQTL 資料），教師可依時間選擇示範或指定為作業。
- 本站的章節分組（四個部分）是為了 14 小時課程規劃自行安排的，可在 `mkdocs.yml` 的 `nav` 調整。

## 網站功能

- 上方分頁切換大單元，左側選單切換章節，右側是本頁目錄。
- 右上角搜尋可以找全站關鍵字，例如輸入 `REGENIE` 會列出所有提到它的段落。
- 程式碼區塊右上角有複製鈕。
- 每頁右上角的鉛筆圖示可直接到 GitHub 編輯該頁。
