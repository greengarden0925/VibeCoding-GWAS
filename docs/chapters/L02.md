# L02 環境建置：VS Code、Claude Code、Python、Git 與 PLINK

## 學習目標

- 打開終端機（terminal），執行並看懂最基本的指令。
- 安裝 VS Code 與 Claude Code 擴充套件，並登入。
- 安裝並確認 Python、Git、PLINK 可以使用。
- 建立本課程的專案資料夾結構。

## 時間配置

| 段落 | 時間 | 內容 |
|---|---|---|
| 觀念 | 10 分鐘 | 為什麼 GWAS 要用終端機；本課程的工具組合 |
| 實作 | 40 分鐘 | 安裝與確認 |
| 驗證 | 10 分鐘 | 每人截圖版本號 |

## 1. 為什麼要用終端機

GWAS 的主要工具（例如 PLINK、REGENIE）都是命令列程式，沒有按鈕介面。一次 GWAS 會處理數十萬到數百萬個遺傳變異，用指令可以完整記錄每一步、重複執行，也方便放到伺服器上跑。

AI 程式助理在這裡的角色，是幫你寫出這些指令並解釋它們。

## 2. 本課程的工具組合

| 工具 | 用途 | 確認指令 |
|---|---|---|
| 終端機 | 輸入指令 | macOS「終端機」；Windows 建議安裝 WSL（Windows Subsystem for Linux） |
| Python 3 | 整理資料、畫圖 | `python3 --version` |
| Git | 版本控制（L04） | `git --version` |
| VS Code ＋ Claude Code 擴充套件 | 編輯器與 AI 程式助理，可以直接讀寫你資料夾裡的檔案並執行指令（本課程預設） | VS Code 狀態列右下角看得到「✻ Claude Code」 |
| PLINK 1.9 與 PLINK 2 | GWAS 主要分析工具（L06 起） | `plink --version`、`plink2 --version` |

!!! note "不一定要用 Claude Code"
    本課程以 Claude Code 示範，因為它能在終端機裡直接讀取資料夾、執行指令。Cursor、GitHub Copilot 等其他 AI 程式工具也可以完成本課程，提示詞原則相同。依 Claude Code 官方文件，使用 Claude Code 需要 Claude 付費訂閱或 Claude Console 帳號（[Quickstart](https://code.claude.com/docs/en/quickstart)）。

## 3. 安裝 VS Code 與 Claude Code 擴充套件（本課程預設）

本課程所有操作都在 **VS Code 裡的 Claude Code 面板**進行。完整圖解見 [VS Code 操作畫面導覽](../vscode.md)，這裡列出最短路徑：

<span class="vg-step">1</span> 到 <https://code.visualstudio.com/> 下載並安裝 VS Code（需要 1.94.0 以上）。

<span class="vg-step">2</span> 打開 VS Code，按 ++ctrl+shift+x++（Mac ++cmd+shift+x++），搜尋 `Claude Code`，按 **Install**。

<span class="vg-step">3</span> 點視窗右下角狀態列的 **✻ Claude Code**，第一次會出現登入畫面，按 **Sign in**，在瀏覽器完成授權。

<span class="vg-step">4</span> 提示框下方的權限模式切到 **Manual**。前幾週每個改檔案、執行指令的動作都先讓你確認。

!!! note "什麼時候還需要命令列版"
    擴充套件內含自己的一份 Claude Code，面板直接可用。如果你想在 VS Code 的終端機裡輸入 `claude` 指令（例如之後在伺服器上用），才需要另外安裝命令列版。以下指令取自官方 [Quickstart](https://code.claude.com/docs/en/quickstart)（2026-11-19 擷取）：

    === "macOS、Linux、WSL"

        ```bash
        curl -fsSL https://claude.ai/install.sh | bash
        ```

    === "Windows PowerShell"

        ```powershell
        irm https://claude.ai/install.ps1 | iex
        ```

    === "套件管理工具"

        ```bash
        brew install --cask claude-code      # macOS Homebrew
        winget install Anthropic.ClaudeCode  # Windows WinGet
        ```

    裝好後在終端機輸入 `claude --version` 確認。

## 4. 建立專案資料夾並在 VS Code 打開

<span class="vg-step">1</span> 在 VS Code 按 `` Ctrl+` ``（反引號鍵，在 Esc 下方；Mac 也是 Ctrl）打開整合式終端機，或從選單 **Terminal → New Terminal**。

<span class="vg-step">2</span> 在終端機輸入：

```bash
mkdir -p ~/vibegwas/{data,scripts,results,figures}
```

<span class="vg-step">3</span> 選單 **File → Open Folder…**，選剛建立的 `vibegwas`，按「選擇資料夾」。左邊檔案總管應該看到 `data`、`figures`、`results`、`scripts` 四個資料夾。

<span class="vg-step">4</span> 點右下角 **✻ Claude Code** 打開面板。從現在起，Claude 只會看到 `vibegwas` 這個資料夾。

## 5. 第一個任務：請 AI 幫你檢查環境

<span class="vg-step">1</span> 在 Claude Code 提示框貼上：

```text
請幫我檢查這台電腦是否已安裝 python3、git、plink、plink2，
列出每個工具的版本號。還沒安裝的，請告訴我在我的作業系統上該怎麼安裝，
但先不要自動安裝，等我確認。
```

<span class="vg-step">2</span> 按 ++enter++ 送出。Claude 會想執行 `python3 --version` 之類的指令，在 Manual 模式下會先跳出詢問，看清楚指令內容再允許。

<span class="vg-step">3</span> 看它整理的表格。對每一個「已安裝」的工具，自己在終端機再打一次版本指令，確認數字一樣。

!!! tip "為什麼要說「先不要自動安裝」"
    AI 程式助理可以直接執行指令。養成習慣：**會改動系統的步驟，先讓它說明要做什麼，你同意再執行。**

## 6. 安裝 PLINK

PLINK 由 Shaun Purcell 與 Christopher Chang 開發，官方網站是 <https://www.cog-genomics.org/plink/2.0/>。GWASTutorial 的安裝步驟是從官方網站下載對應作業系統的壓縮檔、解壓縮後放進 PATH（[GWASTutorial: Data QC](https://cloufield.github.io/GWASTutorial/04_Data_QC/)）。版本會持續更新，請到官方網站下載最新版，不要照抄舊教學裡的檔名。

可以請 AI 幫忙：

```text
我要安裝 PLINK 1.9 和 PLINK 2。請先告訴我官方下載網址，
然後根據我的作業系統，一步步告訴我下載、解壓縮、加入 PATH 的指令，
每一步做完我會回報結果。
```
