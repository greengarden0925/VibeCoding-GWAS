## 1. 常見格式

| 格式 | 副檔名 | 內容 | 常見來源 |
|---|---|---|---|
| VCF | `.vcf`、`.vcf.gz` | 文字格式，每列一個變異，每欄一個樣本 | 定序資料、填補（imputation）伺服器輸出 |
| PLINK 1 binary | `.bed` `.bim` `.fam` | 二進位基因型＋變異資訊＋樣本資訊 | 晶片資料、本課程練習資料 |
| PLINK 2 | `.pgen` `.pvar` `.psam` | PLINK 1 的新版，可存劑量（dosage） | 大型生物資料庫 |
| BGEN | `.bgen` `.sample` | 壓縮的劑量格式 | UK Biobank 填補資料 |
| 摘要統計（summary statistics） | `.tsv` 等 | 每個變異的效應值、標準誤、p 值 | GWAS 輸出、GWAS Catalog |

GWAS 的**輸入**是個人層級基因型（前四種），**輸出**是摘要統計。第四部分的後續分析大多只需要摘要統計，這也是頂尖期刊論文能整合數十個世代資料的原因：各世代只要分享摘要統計，不必交換個人資料。

## 2. PLINK 1 三個檔案

`.fam`（每列一個樣本，6 欄）：

| 欄 | 內容 |
|---|---|
| 1 | 家族 ID（FID） |
| 2 | 個人 ID（IID） |
| 3 | 父親 ID（0 表示不在資料中） |
| 4 | 母親 ID |
| 5 | 性別（1 男、2 女、0 未知） |
| 6 | 表現型（病例對照時 1 對照、2 病例；−9 或 0 為缺失） |

`.bim`（每列一個變異，6 欄）：

| 欄 | 內容 |
|---|---|
| 1 | 染色體 |
| 2 | 變異 ID |
| 3 | 遺傳距離（cM，常為 0） |
| 4 | 物理位置（bp） |
| 5 | 對偶基因 1（通常為次要對偶基因） |
| 6 | 對偶基因 2 |

`.bed` 是二進位檔，不能直接用文字編輯器看，要透過 PLINK 讀取。

## 3. 練習資料集

本課程使用 [GWASTutorial](https://cloufield.github.io/GWASTutorial/01_Dataset/) 的範例資料：1000 Genomes Project 東亞族群 504 人的體染色體 SNP，教學作者另外加入了少量缺失值以便練習 QC。表現型 `1kgeas_binary.txt` 是用 GCTA 模擬的二元性狀，設定 5 個致病 SNP（列在 `causal.snplist`）。

!!! tip "為什麼用模擬表現型很適合教學"
    因為我們**知道正確答案**：致病 SNP 是哪 5 個。學生做完 GWAS 後，可以檢查自己是否找回這些位點。這正是 vibe coding 最需要的驗證依據。

下載方式（GWASTutorial 提供的腳本）：

```bash
cd ~/vibegwas
git clone https://github.com/Cloufield/GWASTutorial.git
cd GWASTutorial/01_Dataset
./download_sampledata.sh
```

這個腳本會下載壓縮檔並解壓出三個檔案：

```text
1KG.EAS.auto.snp.norm.nodup.split.rare002.common015.missing.bed
1KG.EAS.auto.snp.norm.nodup.split.rare002.common015.missing.bim
1KG.EAS.auto.snp.norm.nodup.split.rare002.common015.missing.fam
```

同一個資料夾裡還有表現型 `1kgeas_binary.txt` 與致病 SNP 清單 `causal.snplist`。

## 4. 實作：資料概況腳本

```text
資料在 GWASTutorial/01_Dataset/，檔名前綴是
1KG.EAS.auto.snp.norm.nodup.split.rare002.common015.missing。
請寫一個 bash 腳本 scripts/01_overview.sh，回報：
(1) 樣本數（.fam 列數）；(2) 變異數（.bim 列數）；
(3) 每條染色體的變異數；(4) 表現型檔 1kgeas_binary.txt 的前 5 列與病例、對照人數。
只讀取，不要修改任何檔案。
```

## 驗證清單

- [ ] 樣本數為 504（GWASTutorial 資料說明）。
- [ ] 變異數為 1,235,116。這個數字可以對照 GWASTutorial QC 頁面 `.imiss` 輸出的 `N_GENO` 欄位（每個樣本被檢查的變異數）。
