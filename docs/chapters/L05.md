## 1. 從病例對照研究到 GWAS

公衛學生熟悉的病例對照研究，是比較病例組與對照組的**暴露**比例。GWAS 做的事情一樣，只是把「暴露」換成「帶有某個遺傳變異的對偶基因數」，而且同時對全基因體的每一個變異各做一次。

| 流行病學研究 | GWAS |
|---|---|
| 一個暴露變項 | 數十萬到數千萬個遺傳變異，各自當成一個暴露 |
| 暴露有或無 | 帶有 0、1 或 2 個效應對偶基因（加成模型） |
| 調整年齡、性別 | 調整年齡、性別與基因主成分（PC） |
| 一個 p 值 | 每個變異一個 p 值 |

## 2. 基本名詞

- **SNP（single nucleotide polymorphism）：** 基因體上某一個位置，在族群中出現兩種以上的鹼基。例如有人是 A，有人是G。
- **對偶基因（allele）：** 每個位置的不同版本。人有兩套染色體，所以每個位置有兩個對偶基因，組合起來就是基因型（例如 AA、AG、GG）。
- **次要對偶基因頻率（minor allele frequency, MAF）：** 族群中較少見那個對偶基因的比例。
- **連鎖不平衡（linkage disequilibrium, LD）：** 鄰近的變異常常一起遺傳，所以它們的基因型高度相關。這代表 GWAS 找到的顯著 SNP 不一定是致病變異本身，可能只是和真正致病變異「綁在一起」。這也是第四部分精細定位（fine-mapping）要解決的問題。

## 3. 統計模型

二元表現型（病例對照）通常用 logistic regression，連續表現型（例如血壓）用線性迴歸：

```text
logit P(Y = 1) = β0 + β1·G + γ1·Age + γ2·Sex + Σ δk·PCk
```

其中 G 是效應對偶基因的個數（0、1、2）。exp(β1) 就是每多一個效應對偶基因的勝算比。

## 4. 多重檢定與全基因體顯著閾值

同時檢定幾十萬個變異，用 0.05 當閾值會出現大量假陽性。GWAS 慣用 p < 5×10⁻⁸ 作為全基因體顯著閾值。Marees 等人（2018）的教學文章整理：模擬研究顯示，這個閾值足以控制歐洲族群全基因體中獨立 SNP 的數量，與研究實際的 SNP 密度無關；分析非洲族群時，因遺傳多樣性較高，需要更嚴格的閾值（約 1×10⁻⁸）。常見的直觀理解是「約一百萬個獨立檢定做 Bonferroni 校正」：0.05 ÷ 10⁶ = 5×10⁻⁸。

## 5. 兩張必畫的圖

- **Manhattan plot：** 橫軸是染色體位置，縱軸是 −log₁₀(p)。顯著位點會像高樓一樣突出。
- **QQ plot：** 比較觀察到的 p 值分布與「完全沒有關聯時」應有的分布。若整條線一開始就往上偏，表示有系統性膨脹，可能是族群分層或其他偏誤。

**基因體膨脹係數** λGC = 觀察到的卡方統計量中位數 ÷ 自由度 1 的卡方分布中位數（約 0.455）。接近 1 表示沒有明顯膨脹。不過，多基因性高的性狀在大樣本下 λGC 本來就會大於 1，要區分「真訊號」與「偏誤」，需要第四部分的 LD score regression（Bulik-Sullivan et al., 2015）。

## 6. 族群分層：GWAS 版的干擾因子

若病例組剛好較多來自某個族群，而某個 SNP 在該族群頻率本來就比較高，這個 SNP 就會看起來和疾病有關。這和流行病學的干擾（confounding）是同一件事。解法是：

1. 只分析同一族群的人，或
2. 把基因主成分（PC）放進模型當共變項（L08），或
3. 使用混合模型（L09）。

## 7. 實作：請 AI 模擬一個 SNP 並解釋

```text
請用 Python 模擬 1000 人的資料：一個 SNP 的效應對偶基因頻率 0.3，
依 Hardy-Weinberg 平衡產生 0/1/2 基因型；疾病盛行率約 20%，
每多一個效應對偶基因勝算比 1.5。然後跑 logistic regression，
印出估計的勝算比與 95% 信賴區間。請解釋為什麼估計值不會剛好等於 1.5。
```

## 練習

??? question "某 SNP 的 p 值是 1×10⁻⁶，算不算全基因體顯著？"

??? success "查看答案"

    不算。10⁻⁶ 大於 5×10⁻⁸。這種位點常被稱為「suggestive」，需要更大樣本或重複驗證。

??? question "QQ plot 只有最右上角少數點偏離對角線，代表什麼？"

??? success "查看答案"

    通常代表有少數真正的關聯訊號，而整體沒有系統性膨脹。若是從最左下角開始整條線就偏離，才要懷疑族群分層或其他偏誤。
