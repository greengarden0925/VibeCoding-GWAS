# L07 品質控制（QC）

## 學習目標

- 說出 GWAS 前的七個品質控制步驟與各自要排除的問題。
- 請 AI 寫出 PLINK 品質控制腳本，並逐步回報樣本與變異的變化。
- 判斷 AI 選用的閾值是否有文獻依據。

## 時間配置

| 段落 | 時間 | 內容 |
|---|---|---|
| 觀念 | 15 分鐘 | 七個 QC 步驟與閾值 |
| 實作 | 35 分鐘 | 逐步計算缺失率、頻率、HWE、異型合子率，產出乾淨資料 |
| 驗證 | 10 分鐘 | 對照 GWASTutorial 的數字 |

## 1. 為什麼要 QC

原始基因型資料一定有錯：晶片判讀失敗、樣本汙染、樣本弄混、親屬重複收案。這些錯誤都會造成假陽性或假陰性。QC 的目標是**移除不可靠的樣本與變異**，並把每一步移除多少寫進論文方法。

## 2. 七個 QC 步驟

以下整理自 Marees 等人（2018）的表 1，閾值是該文的建議值，實際研究可依樣本數與設計調整，但都要能說明理由。

| 步驟 | PLINK 參數 | 排除的問題 | Marees 等人的建議 |
|---|---|---|---|
| 1. 缺失率 | `--geno`、`--mind` | 判讀失敗的變異與樣本 | 先用寬鬆閾值 0.2，再用嚴格閾值 0.02；先篩變異再篩樣本 |
| 2. 性別不符 | `--check-sex` | 樣本弄混 | 男性 X 染色體同型合子估計值 > 0.8，女性 < 0.2 |
| 3. 次要對偶基因頻率 | `--maf` | 罕見變異檢定力低、易判讀錯誤 | 大樣本（N ≈ 100,000）常用 0.01，中樣本（N ≈ 10,000）常用 0.05 |
| 4. Hardy-Weinberg 平衡 | `--hwe` | 判讀錯誤 | 二元性狀：病例 p < 1e−10、對照 p < 1e−6 排除；連續性狀 p < 1e−6 |
| 5. 異型合子率 | `--het` | 樣本汙染、近親婚配 | 排除偏離平均 ±3 個標準差的樣本 |
| 6. 親緣關係 | `--genome`（PLINK 2 可用 `--king-cutoff`） | 隱藏的親屬關係 | 族群樣本建議 pi-hat > 0.2（約二等親）排除 |
| 7. 族群分層 | `--mds-plot`、`--pca` | 族群結構造成的干擾 | 見 [L08](L08.md) |

!!! note "本練習資料的特殊情況"
    練習資料只有體染色體（檔名中的 `auto`），所以無法做性別檢查。GWASTutorial 的關聯分析紀錄也顯示樣本性別都是未知（「500 ambiguous」）。

## 3. 實作：逐步 QC

以下指令取自 [GWASTutorial: Data QC](https://cloufield.github.io/GWASTutorial/04_Data_QC/)。請先自己讀懂，再請 AI 把它們整理成一個可重複執行的腳本。

設定輸入檔：

```bash
genotypeFile="../01_Dataset/1KG.EAS.auto.snp.norm.nodup.split.rare002.common015.missing"
```

**步驟 1：缺失率**

```bash
plink --bfile ${genotypeFile} --missing --out plink_results
```

輸出 `plink_results.imiss`（每個樣本）與 `plink_results.lmiss`（每個變異），`F_MISS` 欄是缺失比例。

**步驟 2：對偶基因頻率**

```bash
plink2 --bfile ${genotypeFile} --freq --out plink_results
```

**步驟 3：Hardy-Weinberg 平衡**

```bash
plink --bfile ${genotypeFile} --hardy --out plink_results
```

**步驟 4：LD 修剪（pruning），供異型合子率與親緣計算使用**

```bash
plink \
    --bfile ${genotypeFile} \
    --maf 0.01 \
    --geno 0.02 \
    --mind 0.02 \
    --hwe 1e-6 \
    --indep-pairwise 50 5 0.2 \
    --out plink_results
```

`--indep-pairwise 50 5 0.2` 表示：每次看 50 個 SNP 的視窗，每次往前移 5 個，視窗內兩兩 r² > 0.2 就移除其中一個。輸出 `plink_results.prune.in` 是保留下來的近似獨立 SNP。

**步驟 5：異型合子率**

```bash
plink --bfile ${genotypeFile} --extract plink_results.prune.in --het --out plink_results
awk 'NR>1 && $6>0.1 || $6<-0.1 {print $1,$2}' plink_results.het > high_het.sample
```

GWASTutorial 用近交係數 F 的絕對值大於 0.1 當標準；Marees 等人建議 ±3 個標準差。這就是「閾值需要說明理由」的例子，課堂上可以讓 AI 兩種都算，比較排除的人數。

**步驟 6：產出乾淨資料**

```bash
plink \
    --bfile ${genotypeFile} \
    --maf 0.01 \
    --geno 0.02 \
    --mind 0.02 \
    --hwe 1e-6 \
    --remove high_het.sample \
    --keep-allele-order \
    --make-bed \
    --out sample_data.clean
```

親緣關係的排除，GWASTutorial 放在下一章 PCA 步驟中用 `plink2 --king-cutoff 0.0884` 處理。

## 4. 在 VS Code 用 Claude Code 逐步操作

以下每一步都在 VS Code 完成。畫面位置請對照 [VS Code 操作畫面導覽](../vscode.md)。

<span class="vg-step">1</span> **打開專案。** VS Code 選單 **File → Open Folder…** 選 `vibegwas`，點右下角 **✻ Claude Code** 打開面板。確認檔案總管裡看得到 L06 下載的 `GWASTutorial/01_Dataset/`。

<span class="vg-step">2</span> **切到 Plan 模式，先要計畫。** 點提示框下方的權限模式，選 **Plan**，貼上：

!!! prompt "提示詞"

    ```text
    我要做 GWAS 的品質控制。請規劃一支 scripts/02_qc.sh，內容是 L07 講義的步驟 1–6
    （--missing、--freq、--hardy、LD 修剪、--het、產出 sample_data.clean），指令照
    GWASTutorial 原樣，只把路徑改成：
    - 輸入：GWASTutorial/01_Dataset/1KG.EAS.auto.snp.norm.nodup.split.rare002.common015.missing
    - 輸出：results/qc/，檔名前綴 plink_results
    要求：
    1. 每一步執行完，從該步的 .log 讀出樣本數與變異數並印出。
    2. 最後產出 results/qc/qc_summary.tsv，欄位 step、n_samples、n_variants。
    3. 不要修改 GWASTutorial/01_Dataset 裡的任何檔案。
    ```

<span class="vg-step">3</span> **審計畫。** VS Code 會把計畫開成一份 Markdown 文件。逐條對照本章第 3 節的指令，特別檢查：

有問題就直接在計畫文件上加註解，或在提示框告訴它，例如「異型合子率門檻維持 0.1，不要改成 3 個標準差」。

<span class="vg-step">4</span> **切回 Manual，讓它寫檔。** 同意計畫後把模式切回 **Manual**。Claude 建立 `scripts/02_qc.sh` 時會跳出左右對照畫面，右邊是新內容。讀過一遍再按接受。

<span class="vg-step">5</span> **執行。** 你可以讓 Claude 執行（它會先問你是否允許 `bash scripts/02_qc.sh`），也可以自己在 VS Code 終端機輸入：

<span class="vg-step">6</span> **驗證。** 如果已經照[建立與安裝 Skill](../skills.md) 裝好課程 skill，在提示框輸入：

## 練習

??? question "為什麼異型合子率與親緣計算要先做 LD 修剪？"

??? success "查看答案"

    這兩項計算假設 SNP 彼此獨立。高度連鎖的 SNP 會重複計算同一段基因體的資訊，使估計偏誤。Marees 等人的表 1 也指出，親緣計算應使用經過修剪的獨立 SNP，且只用體染色體。
