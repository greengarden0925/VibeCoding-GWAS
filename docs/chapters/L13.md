## 1. 孟德爾隨機化：基因當工具變數

觀察性研究中，暴露（例如 BMI）與結果（例如第二型糖尿病）的關聯可能被干擾因子扭曲。基因型在受孕時隨機分配，比較不受生活型態干擾，所以可以把與暴露強烈相關的 SNP 當成**工具變數**。

三個核心假設：

1. **關聯性：** SNP 與暴露強烈相關（通常選 p < 5×10⁻⁸ 的 SNP）。
2. **獨立性：** SNP 與暴露–結果之間的干擾因子無關。
3. **排除限制：** SNP 只透過暴露影響結果，沒有其他路徑（沒有水平多效性）。

| 方法 | 處理的問題 |
|---|---|
| 逆變異數加權（IVW） | 主要估計，假設所有 SNP 都是有效工具 |
| MR-Egger | 允許平均方向性的多效性，截距可檢定多效性 |
| 加權中位數（weighted median） | 只要一半以上權重來自有效工具，估計仍一致 |
| MR-PRESSO | 偵測並移除離群 SNP（Verbanck et al., 2018） |

報告 MR 研究時，應依照 STROBE-MR 規範（Skrivankova et al., 2021）。

## 2. TwoSampleMR 流程

TwoSampleMR 套件（Hemani et al., 2018）把 MR 標準化為幾個步驟。GWASTutorial 的[範例](https://cloufield.github.io/GWASTutorial/TwoSampleMR/)以韓國 KoGES 的 BMI GWAS 為暴露、Biobank Japan 的第二型糖尿病 GWAS 為結果：

```r
library(TwoSampleMR)

# 1. 暴露：取 p < 5e-8 的 SNP，格式化，再用東亞 LD 參考 clump
exp_dat <- format_data(exp_raw, type = "exposure", ...)
clumped_exp <- clump_data(exp_dat, clump_r2 = 0.01, pop = "EAS")

# 2. 結果：讀入結果 GWAS 並格式化
out_dat <- format_data(out_raw, type = "outcome", ...)

# 3. 對齊對偶基因方向
harmonized_data <- harmonise_data(clumped_exp, out_dat, action = 1)

# 4. 主要分析與敏感度分析
res <- mr(harmonized_data)
mr_heterogeneity(harmonized_data)
mr_pleiotropy_test(harmonized_data)
res_loo <- mr_leaveoneout(harmonized_data)
```

（`...` 為欄位對應參數，完整程式見 GWASTutorial。）

**頂尖期刊實例（方法段落原文查證）：**

- **肥厚型心肌病變（Tadros et al., 2025）：** MR 支持左心室收縮力增加對阻塞型與非阻塞型 HCM 的因果角色；並用 MR-PRESSO 的三個步驟（整體多效性檢定、移除離群值、比較移除前後估計）評估多效性。
- **多族群憂鬱症（Meng et al., 2024）：** MR 分析依照 STROBE-MR 規範報告；歐洲族群部分以 UK Biobank 選出 BMI、空腹血糖、HDL、LDL、收縮壓與三酸甘油酯的工具變數。
- **焦慮症（Strom et al., 2026）：** 用 GSMR 對焦慮症與憂鬱症、創傷後壓力症候群、神經質做雙向分析。

## 3. 多基因風險分數

PRS 把個人帶有的風險對偶基因，依 GWAS 效應值加權加總：

```text
PRS_i = Σ_j β_j × G_ij
```

其中 β_j 是第 j 個 SNP 在**外部** GWAS 的效應值，G_ij 是個人 i 帶有的效應對偶基因數。

| 方法 | 做法 | 原始文獻 |
|---|---|---|
| Clumping + thresholding（C+T） | 先 clump 取近似獨立 SNP，再選不同 p 值門檻 | PLINK `--score` |
| PRS-CS | 用貝氏連續收縮先驗與 LD 參考調整所有 SNP 的效應 | Ge et al., 2019 |
| PRS-CSx | PRS-CS 的多族群版本，整合不同族群的 GWAS | Ruan et al., 2022 |
| LDpred2 | 貝氏方法，`auto` 模式可自動估計參數 | Privé et al., 2021 |

GWASTutorial 的 [PRS 範例](https://cloufield.github.io/GWASTutorial/10_PRS/)以 C+T 示範，用 PLINK 2 一次算出多個 p 值門檻的分數：

```bash
# 建立 p 值門檻
cat > range_list << EOF
pT0.001 0 0.001
pT0.05 0 0.05
pT0.1 0 0.1
pT0.2 0 0.2
pT0.3 0 0.3
pT0.4 0 0.4
pT0.5 0 0.5
EOF

plink2 \
    --bfile ${plinkFile} \
    --score ${sumStats} 1 2 3 header cols=nallele,scoreavgs,denom,scoresums \
    --q-score-range range_list SNP.pvalue \
    --extract 1kgeas.valid.snp \
    --out 1kgeas
```

輸出 7 個 `.sscore` 檔，每個門檻一個。

!!! warning "PRS 的兩個常見錯誤"
    1. **樣本重疊：** 計算效應值的 GWAS 與計分的樣本不能是同一群人，否則預測力會被高估。心臟衰竭 GWAS 在 UK Biobank 驗證 PRS 時，使用的權重就來自**排除 UK Biobank** 的統合分析（Henry et al., 2025）。
    2. **跨族群可轉移性：** 以歐洲族群 GWAS 建立的 PRS，在其他族群的預測力通常較差，這是 PRS-CSx 等多族群方法要解決的問題（Ruan et al., 2022）。

**頂尖期刊實例（方法段落原文查證）：**

- **心臟衰竭（Henry et al., 2025）：** 以 LDpred2-auto 從 1,012,059 個變異建立 PRS，權重來自排除 UK Biobank 的統合分析，在 347,235 名 UK Biobank 歐洲族群參與者中驗證。
- **焦慮症（Strom et al., 2026）：** 在 GenoPred 流程中使用 MegaPRS（基於 LDAK 遺傳力模型）計算 PRS，並在歐洲、非洲與南亞族群中評估。
