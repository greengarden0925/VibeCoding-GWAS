# L10 結果視覺化與解讀

## 學習目標

- 請 AI 從 PLINK 2 結果畫出 Manhattan plot 與 QQ plot，並計算基因體膨脹係數 λGC。
- 用 clumping 把顯著 SNP 整理成獨立位點。
- 查詢 GWAS Catalog，判斷位點是否曾被報告過。
- 寫出一段只根據自己結果的結果描述。

| 段落 | 時間 | 內容 |
|---|---|---|
| 實作一 | 20 分鐘 | Manhattan、QQ、λGC |

## 1. 畫圖

GWASTutorial 使用 Python 套件 gwaslab 畫圖（[GWASTutorial: Visualization](https://cloufield.github.io/GWASTutorial/Visualization/)）。初學者也可以請 AI 用 pandas 與 matplotlib 自己寫，好處是每一步都看得懂。

```text
請寫 scripts/05_plot.py，讀取 results/gwas/1kgeas.B1.glm.firth（tab 分隔，表頭第一欄是 #CHROM）。
步驟：
1. 排除 ERRCODE 不是 "." 或 P 為 NA 的列，印出排除了幾列。
2. Manhattan plot：x 軸依染色體 1–22 排列位置，y 軸 -log10(P)，
   染色體顏色交替，畫一條 5e-8 的紅色水平線。存成 figures/manhattan.png。
3. QQ plot：期望 -log10(P) 對觀察 -log10(P)，加上對角線。存成 figures/qq.png。
4. 計算 λGC：把 P 轉成自由度 1 的卡方值，取中位數除以 0.4549，印到小數第三位。
5. 印出 P < 5e-8 的變異數。
```

!!! tip "驗證圖是否正確的三個問題"
    1. Manhattan plot 的染色體順序是 1 到 22，而不是 1、10、11……（字串排序的錯誤）。
    2. 紅線的高度約在 y = 7.3（因為 −log₁₀(5×10⁻⁸) ≈ 7.3）。
    3. 最高的峰是否落在 [L09](L09.md) 列出的致病 SNP 所在的染色體。

## 2. Clumping：把 SNP 整理成位點

一個真正的訊號周圍會有一大群因 LD 而一起顯著的 SNP。Clumping 以最顯著的 SNP 為中心，把與它高度連鎖的 SNP 歸成同一群。以下指令取自 GWASTutorial：

```bash
plinkFile=../04_Data_QC/sample_data.clean
sumStats=../06_Association_tests/1kgeas.B1.glm.firth

plink \
    --bfile ${plinkFile} \
    --clump-p1 0.0001 \
    --clump-r2 0.1 \
    --clump-kb 250 \
    --clump ${sumStats} \
    --clump-snp-field ID \
    --clump-field P \
    --out 1kg_eas
```

| 參數 | 意義 |
|---|---|
| `--clump-p1 0.0001` | P < 10⁻⁴ 的 SNP 才能當群的中心 |
| `--clump-r2 0.1` | 與中心 SNP 的 r² > 0.1 就歸入同一群 |
| `--clump-kb 250` | 只看中心 SNP 前後 250 kb |

GWASTutorial 的執行紀錄顯示「40 clumps formed from 307 top variants」，第一個群的中心 SNP 是 `2:55513738:C:T`（P = 1.69×10⁻¹⁵）。你的結果應該相同。

頂尖期刊常用 FUMA 定義位點。例如 Kim 等人（2024）的帕金森氏症 GWAS，在方法段落說明 FUMA 先以 r² < 0.6 的條件 clump 出獨立顯著 SNP，再據此定義基因體風險位點。

## 3. 查詢 GWAS Catalog

[GWAS Catalog](https://www.ebi.ac.uk/gwas/)（Sollis et al., 2023）收錄已發表 GWAS 的顯著結果。請 AI 協助：

```text
請把 clumping 結果 1kg_eas.clumped 中 P < 5e-8 的中心 SNP 整理成表格，
欄位：CHR、BP、SNP、P、群內 SNP 數。
然後告訴我在 GWAS Catalog 網站上怎麼用染色體位置查詢這些位點。
注意：本資料座標是 hg19（GRCh37），GWAS Catalog 目前使用 GRCh38，
查詢前要提醒我座標系統不同。
```

!!! warning "模擬資料的提醒"
    本練習的表現型是模擬的，所以 GWAS Catalog 查到的結果與本資料沒有生物學關係。這一步是練習查詢流程。

## 4. 寫結果段落

請 AI 依據**你的**輸出檔寫一段結果，並要求它標出每個數字的來源檔：

```text
請根據 results/qc/qc_summary.tsv、results/gwas/ 的輸出與 λGC，寫一段約 150 字的英文結果描述。
每個數字後面用括號標出它來自哪個檔案。不要加入任何檔案中沒有的數字或解釋。
```

寫完後逐一核對每個數字。這個習慣可以避免 AI 自行補上看起來合理、但你沒有算過的數字。
