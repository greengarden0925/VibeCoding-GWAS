# 影片總表

本頁列出 14 章講義引用的全部 YouTube 影片，共 51 支。

## 怎麼挑出來的

1. 2026-11-19 在 YouTube 以英文與中文關鍵字搜尋（例如 `vibe coding full course beginners`、`claude code tutorial for beginners`、`Claude Code 教學 新手`、`PLINK tutorial GWAS`、`fine-mapping GWAS SuSiE`、`mendelian randomization tutorial`），其中 vibe coding 主題另外以「依觀看次數排序」搜尋。
2. 從搜尋結果挑選三類影片：觀看次數高的入門課、近一年內上架的新課、以及學術單位（International Statistical Genetics Workshop、Broad Institute、Computational Genomics Summer Institute 等）的方法課。
3. 每支影片的標題、頻道、上架日、長度與觀看次數都是直接讀取該影片頁面的資料，沒有估算。

!!! note "關於「近期」與「觀看次數多」的取捨"
    Vibe coding 是 2025 年 2 月才出現的名詞，所以相關影片幾乎都是近一年多上架，觀看次數也高。GWAS 方法類影片多為學術單位錄製，觀看次數通常只有數百到數萬，且許多經典課是 2021 年以前的錄影。這類影片仍然收錄，因為方法本身沒有過時；表中保留上架日，方便自行判斷。
