# Vibe Coding × GWAS

給公共衛生與生醫領域研究生的 14 小時課程講義：從零開始用 AI 寫程式（vibe coding），完整做完一次全基因體關聯研究（GWAS），並拆解 2024–2026 年 Nature Genetics 等頂尖期刊 GWAS 論文常用的後續分析方法。

網站：<https://greengarden0925.github.io/vibecoding-gwas/>

## 內容

- 14 章講義，每章 1 小時，分為四部分：Vibe coding 基礎、GWAS 觀念與資料、完成一次 GWAS、頂尖期刊的後續分析方法。
- 51 支 YouTube 教學影片總表（觀看次數與上架日取自 YouTube，2026-11-19）。
- 6 篇 Nature Genetics 2024–2026 GWAS 論文的方法盤點。
- 實作以 [GWASTutorial](https://cloufield.github.io/GWASTutorial/) 的 1000 Genomes 東亞族群範例資料為基礎。
